# Klau Portfolio

Locofy-ból generált React + Vite + MUI portfólió weboldal.

## Indítás

```bash
npm install
npm start
```

A böngészőben: http://localhost:5173

## Parancsok

| Parancs | Leírás |
|---------|--------|
| `npm start` | Fejlesztői szerver (Vite) |
| `npm run build` | Produkciós build |
| `npm run preview` | Build előnézete |

## Struktúra

- `src/pages/Foldal.tsx` – főoldal
- `src/components/` – szekció komponensek
- `public/` – képek és SVG ikonok
